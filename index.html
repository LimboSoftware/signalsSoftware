How publishing works

Press Publish preset to GitHub. You'll see a new GitHub Issue with your preset already filled in. Sign in as the repository owner and press Create on GitHub. The repository automatically publishes the preset onto this homepage. Students never need GitHub accounts. It may take a short while for GitHub Pages to rebuild.

For changes, publish the same preset name again. This updates the button on the student homepage.

This is a public GitHub Pages site. Workshop names and website URLs are public. Do not add links containing private tokens or sign-in credentials. Other GitHub users cannot publish a preset to the live catalogue.
