WORKSHOP HOST

Three pages.
Every MacBook.

Add up to three website links, copy one student link and open those same pages on every workshop MacBook.

Choose your pages

Paste the website URLs below, or capture the first three open Chrome tabs using the optional Mac helper.

If you edit the websites, press Create student link again and share the new link. This test version doesn't update students' pages automatically.

Want to copy existing Chrome tabs?

On the host Mac, open the three sites in the front Chrome window. Click Copy Chrome tab capture command, paste into Terminal and press Return. Allow access to Chrome if prompted. It will open this page with the URLs filled in, ready for you to create a student link.

This GitHub Pages version stores your draft URLs in your browser and encodes them in the student link. Do not include confidential links or passwords in the URLs.
